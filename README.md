# Budget System

Sistema di preventivazione file-based con pubblicazione statica.

## Struttura

- `data/` - Dati JSON preventivi
- `templates/` - Template HTML
- `public/` - Output generato (deploy su GitHub Pages)

## Deploy

`budget.giobi.com` mappato su GitHub Pages via Cloudflare
